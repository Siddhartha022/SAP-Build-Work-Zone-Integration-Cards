# SAP Build Work Zone – Integration Cards

This repository contains my practical learning and implementation examples of SAP UI Integration Cards for SAP Build Work Zone.

## Integration Card Types

1. Analytical Card
2. Calendar Card
3. Content Media Card
4. Donut Chart Card
5. Highlight Card
6. Member Card
7. Numeric Card
8. Object Card
9. Timeline Card

## Purpose

- Understand different Integration Card types.
- Practice card configurations using JSON manifests.
- Learn data binding and data consumption.
- Integrate external OData services.
- Explore SAP Build Work Zone use cases.

## Technologies

- SAP Build Work Zone
- SAP UI5
- Integration Cards
- JSON
- OData Services
- SAP Business Application Studio

**Purpose:** Personal learning, practice, and future project reference.
